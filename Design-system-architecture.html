Проект построен как модульная дизайн-система в Figma, основанная на компонентном подходе. Все интерфейсы формируются из переиспользуемых элементов UI-кита и проходят через итерационные релизы.

Принципы системы

  • Единый UI-кит как источник компонентов
  • Макеты строятся только на компонентах
  • Прототипы используются для проверки UX
  • Итеративное развитие через релизы

Ключевая логика

Система построена по принципу восходящей зависимости: от анализа → к системе компонентов → к макетам → к UX-прототипам. 


Discovery → UI Kit → UI Layer → UX Layer

Слои дизайн-системы

Discovery Layer

Анализ конкурентов, аудитории и UX-паттернов.

UI System

UI-кит: компоненты, цвета, типографика, токены.

UI Layer

Макеты страниц desktop и mobile версии.

UX Layer

Интерактивные прототипы и пользовательские сценарии.

Процесс релизов

Update → UX оптимизация и A/B тесты
Public → Передача в разработку
